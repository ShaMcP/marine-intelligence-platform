# P# Platform Architecture

This directory contains documentation and diagrams describing the architecture of the ATLAS Marine Intelligence Platform.

ATLAS is built on a Databricks Lakehouse using Bronze, Silver, and Gold Delta Lake layers to support species tracking analysis, environmental data integration, and conservation insight generation.

## Files

| File | Description |
|---|---|
| `platform_overview.md` | End-to-end architecture and technology stack |
| `data_layers.md` | Bronze, Silver, and Gold layer detail |
| `data_sources.md` | All data sources and their analytical purpose |
